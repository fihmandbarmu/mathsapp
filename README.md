# 🚀 Math Adventure!
A super fun math game for kids! 

**Age Limit:** 3+
**Levels:** 1 to 6

## How to Play:
1. Double-click the `index.html` file to open the game in your web browser.
2. Look at the math question on the screen.
3. Click the big colorful button that has the correct answer!
4. Get 3 stars to move up to the next level. Can you reach Level 6?

Have fun learning math!
